# Website demo

Folder: website — static HTML/CSS demo matching the provided design images.

Quick steps:

1. Copy the image attachments into `website/images/` and name them `hero-left.jpg` and `hero-small.jpg`.
2. Open the project folder and serve with a simple static server, for example:

```bash
cd "c:\Users\HP\Documents\service pkl\website"
python -m http.server 8000
# then open http://localhost:8000 in your browser
```
